# Modulação - Código Q

### **Código Q - Comunicação Operacional**

Visando tornar a **comunicação mais clara, rápida e eficaz**, a Polícia utiliza o **Código Q** como forma padronizada de linguagem entre os agentes, seja por meio do **rádio** ou através do **/PD (chat da Polícia)**.

O uso correto dos códigos promove agilidade no atendimento, evita ruídos de comunicação e contribui para a segurança das operações.

O **padrão de modulação**, bem como os **significados e aplicações práticas dos Códigos Q**, serão apresentados **de forma detalhada** durante o **Curso de Modulação** e também estarão disponíveis no **Manual de Comunicação Policial**.



#### **CÓDIGOS Q**

| **Código** | **Descrição**    |

| PTR        | Patrulhamento    |

| QSV        | Viatura          |
| QRL        | Ocupado(a)       |
| TKS        | Obrigado(a)      |
| QRU        | Ocorrência       |
| QTX        | Sair de serviço  |
| QRX        | Cessar modulação |
| QRV        | À disposição     |
| QSJ        | Dinheiro         |
| QRA        | Identificação    |
| QSL        | Entendido        |
| QTO        | Pausa            |
| QSM        | Repetir          |
| QTI        | A caminho        |
| QTA        | Cancelar/Sair    |
| QTH        | Localização      |
| QTC        | Mensagem         |
