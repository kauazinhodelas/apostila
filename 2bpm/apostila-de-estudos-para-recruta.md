**Apresentação**

Ao chegar, para se apresentar deverá falar:\
&#xNAN;**“Recruta ‘Fulano’ se apresentando para o recrutamento do 2º Batalhão Policial da Meta City.”**\
Lembrando que você será avaliado pelos recrutadores desde o início até o fim do processo.

***

**Comunicação (Modulação)**

Visando tornar a comunicação mais clara e eficaz, a Polícia utiliza o **código Q** como forma de linguagem entre os agentes, seja por meio do rádio ou pelo **/PD (chat da polícia)**.

O padrão de modulação e os significados correspondentes aos códigos serão explorados de forma mais detalhada durante o curso de modulação e também no respectivo manual.

_**Uso Progressivo da Força**_

\
A Polícia segue um conceito que orienta como a força deve ser usada de forma gradual e proporcional em situações de conflito. A ideia é que os policiais usem só a força necessária para controlar a situação, aumentando o uso da força apenas se for realmente preciso.

| **Nível**                         | **Descrição**                                                |
| --------------------------------- | ------------------------------------------------------------ |
| **Abordagem (Nível 0)**           | Realizar uma abordagem                                       |
| **Normalidade (Nível 1)**         | A presença do policial já é suficiente para controle         |
| **Cooperativo (Nível 2)**         | Verbalização                                                 |
| **Resistência Passiva (Nível 3)** | Separar os indivíduos que estão em conflito, dialogando      |
| **Resistência Ativa (Nível 4)**   | Se nenhuma das anteriores funcionar, pode algemar ou segurar |
| **Agressão Não Letal (Nível 5)**  | Uso do taser                                                 |
| **Agressão Letal (Nível 6)**      | Uso de armas de fogo caso tenha uma ameaça armada            |
